# Vigilia — идея, архитектура, план

## 1. Идея

**Vigilia** (лат. «бодрствование») — маленькое приложение для Windows, которое не даёт ПК уйти в сон.

Главное — одна большая кнопка-«глаз» (орб):
- **выкл** — глаз закрыт, орб тёмный, «спит»;
- **вкл** — глаз открыт и изредка моргает, орб залит акцентом, вокруг «дышит» аура и вращается пунктирная орбита.

Чтобы приложением было удобно пользоваться, одной кнопки мало. Добавлено то, без чего такие утилиты неудобны:
1. **Экран** — «Гаснет / Не гаснет»: держать ли включённым ещё и дисплей (для презентаций и видео) или только систему (для загрузок и рендера).
2. **Таймер** — ∞ / 30м / 1ч / 2ч / 4ч. Кольцо прогресса вокруг орба и обратный отсчёт; по истечении режим выключается сам.
3. **Трей** — закрытие окна прячет его в трей, режим продолжает работать. Иконка в трее меняется по состоянию; левый клик показывает окно, в меню есть «Вкл/Выкл», «Показать» и «Выход».
4. **Автозапуск** с Windows (стартует свёрнутым в трей) и **звуки** — оба переключаются в настройках.
7. Настройки по умолчанию скрыты и открываются кнопкой: панель «вырастает» из неё (добавлено во второй итерации, T10).
5. Приложение запоминает выбранные настройки и включённое состояние без таймера.
6. Запускается только одна копия: повторный запуск показывает уже открытое окно.

Визуальный язык: тёмная палитра Catppuccin Mocha с фиолетовым подтоном во всех слоях, моноширинный шрифт, один акцент, «тройной отклик» на клик (поп, белая вспышка, звук), переключатель-«гусеница», toggle с OutBack, посимвольное появление текста и «дыхание» ауры.

## 2. Архитектура

**Стек:** Flutter (Windows desktop). Он уже настроен на этой машине и знаком по Enitor/Ledgify, а анимации на 60 fps — его сильная сторона. Системные вызовы Windows делаются через `dart:ffi` без обёрток.

**Зависимости:** `window_manager` (окно без рамки, скрытие вместо закрытия), `tray_manager` (иконка в трее), `ffi` (строки UTF-16 и выделение памяти для WinAPI).

```
lib/
  main.dart              бутстрап: окно, трей, контроллер, runApp
  theme.dart             токены: цвета, длительности, кривые (OutBack(s)), lighter/darker
  win32.dart             FFI: PowerCreateRequest/PowerSetRequest/PowerClearRequest,
                         PlaySound, SystemParametersInfo (reduce motion)
  sounds.dart            синтез коротких WAV в памяти (свои звуки, без чужих файлов)
  settings.dart          JSON в %APPDATA%\Vigilia\settings.json; автозапуск через reg.exe (HKCU\...\Run)
  controller.dart        VigilController (ChangeNotifier): active, keepDisplay, timer, endsAt,
                         sounds, autostart; тик таймера; применение power request
  shell.dart             трей + окно: иконка/подсказка/меню по состоянию, скрытие в трей
  ui/
    home.dart            экран: заголовок, орб, статус, карточки настроек
    title_bar.dart       свой заголовок окна (перетаскивание, «в трей»)
    pressable.dart       тройной отклик: hover/press-масштаб, поп, вспышка
    orb.dart             орб: глаз (CustomPainter), аура, орбита, кольцо таймера
    segmented.dart       сегментный переключатель «гусеница»
    toggle.dart          toggle (ручка OutBack 1.2)
    settings_drawer.dart панель настроек, вырастающая из кнопки (T10)
    motion.dart          текст с посимвольным появлением (Letters) и стартовый каскад (Cascade)
windows/runner/main.cpp  одна копия (mutex) + показ существующего окна
assets/tray_on.ico, tray_off.ico, windows/runner/resources/app_icon.ico  (tool/make_icons.py)
test/                    юнит-тесты: цвета, WAV, логика таймера контроллера; smoke-тест виджета
```

**Поток данных:** UI → `VigilController` (единственный источник правды) → `win32` (запрос питания) + `settings` (сохранение) + `sounds`; `shell` и UI слушают контроллер.

**Как не даём уснуть:** `PowerCreateRequest("Vigilia: …")` + `PowerSetRequest(SystemRequired [, DisplayRequired])`. В отличие от `SetThreadExecutionState`, запрос не привязан к потоку и виден в `powercfg /requests` с понятной причиной. Когда процесс завершается, Windows снимает запрос сама, так что «зависнуть» во включённом состоянии нельзя.

## 3. План разработки (задача → жёсткие требования к сдаче)

- ✅ `OutBack(s)` даёт 0 при t=0, 1 при t=1 и перелёт выше 1 при s>0; покрыто тестом.

**T2. Системный слой (FFI).** `win32.dart`: power request, PlaySound, reduce-motion.
